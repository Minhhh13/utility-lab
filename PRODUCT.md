# Utility Lab

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User approved the recommendation: lightweight React with static hosting, progressive web app support, and an iOS native wrapper. Implementation uses Vite, TypeScript, and Capacitor.

## Users

Counter-Strike players looking up utility while playing, and players planning team tactics on desktop or iPhone.

## Product Purpose

A fast smoke and lineup library alongside an editable tactic board. The user explicitly requests a website and iPhone app, optimized for the Steam in-game browser.

## Operating Context

Steam overlay browser during matches; desktop planning; iPhone reference and planning. MetaStack (https://metastack.gg/) is the supplied functional reference, not a request to copy branding or proprietary content.

## Capabilities and Constraints

User ordered the work: first a local tactic board including all maps in CS2, then a MetaStack-inspired utility lineup website across maps/devices, then a playbook. User requested a public source repository but no website publication for this draft. User previously confirmed CS2, an installable web app plus native iOS project, and the recommended stack. The immediate scope is the local board. Local saved tactics, offline caching, and compact overlay mode support the original performance brief. App Store distribution remains undecided. Never present illustrative lineups as verified throws. Do not claim measured Steam overlay or iPhone device performance without testing those environments.

## Evidence on Hand

Empty repository at the start. No user-provided lineup footage, screenshots, branding, team records, or native signing credentials.

## Product Principles

- Reach useful utility information quickly.
- Keep initial transfers and runtime work small.
- Make editing and saved state recoverable.
- Clearly distinguish example planning content from verified lineups.
