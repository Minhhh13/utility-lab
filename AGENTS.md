# Utility Lab workspace rules

These rules apply to this repository and every directory below it, including ignored outputs, scripts, tests, local tools and agent tasks.

## CS2 and Steam are out of bounds

- Never launch Counter-Strike 2 or Steam, open Steam links, start a practice client or dedicated server, or attach to, enumerate, monitor or control their processes.
- Never locate, list, read, create, modify, delete, restore or otherwise interact with the game or Steam installation, libraries, configuration, launch options, bindings, game files, logs or user data. This includes read-only inspection and temporary changes.
- Do not delegate those actions to another agent, script, plugin or browser. Apply the same boundary during troubleshooting, verification and cleanup.
- A request to verify a lineup in game does not waive this rule. Use the website, repository assets, public creator evidence or footage the user supplies. State which evidence was checked and leave independent gameplay verification unconfirmed.

Read [PRODUCT.md](PRODUCT.md) for the scope of the website. If a local HANDOFF.md is present, read it for additional workspace instructions before starting work.
