# Superfuture review notes

Read [Design Review](https://github.com/Superfuture/design-review/blob/main/design-review/skills/design-review/SKILL.md) and its [checklist](https://github.com/Superfuture/design-review/blob/main/design-review/skills/design-review/checklist.md).

Review the complete board flow across hierarchy, typography, spacing, color, motion, states, accessibility, responsiveness, writing and consistency. Findings require a concrete screen or source location, a user consequence and a specific fix. Fix blocking interactions and access failures before minor polish.

Inspect rendered desktop and narrow layouts as well as source. Measure contrast, hit regions and computed type instead of judging them by screenshot alone. Cover empty, loading, error, selected, disabled and editing states. State unverified device behavior explicitly.

The source's telemetry, paid service and promotional steps are not part of this project's review. No artifact is sent to an external review service.
