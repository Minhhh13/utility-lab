# Numbered spawn sheets

On 27 November 2026 the website catalogue contained 129 guides with a publisher-assigned spawn number, covering 28 families on eight maps. Each sheet uses the numbering of the guide being viewed. A sheet can show a neighboring start even when that publisher has no recorded throw from it to the selected destination.

For example, StellaraQWQ’s Dust II T spawn 4 shares coordinates with setpos T14. The Cache CSNADES Garage CT spawn 1 shares coordinates with setpos CT2. The website only shows a sheet when the exact guide URL, map, team, destination floor, utility type and published slot agree. Missing creator slots stay absent, including StellaraQWQ’s Dust II slot 1.

The regressions project all 62 contextual points independently from the stored world coordinates and check each of the 129 selectable starting pins against its registered source origin. These checks establish agreement with public creator evidence. Independent gameplay verification remains unconfirmed.
